# Windows build instructions

## 1. Clone and open

```powershell
git clone https://github.com/BeNNs91/cyber-distortion.git
cd cyber-distortion
```

## 2. Add JUCE

This repository intentionally does **not** commit a broken/empty gitlink. If JUCE is not already present:

```powershell
git submodule add https://github.com/juce-framework/JUCE.git JUCE
git submodule update --init --recursive
```

Commit `.gitmodules` and the JUCE submodule pointer when ready. For reproducible builds, pin the submodule to a tested JUCE release.

## 3. Configure and build

In a Developer PowerShell with Visual Studio C++ build tools installed:

```powershell
cmake -S . -B build -G "Visual Studio 17 2022" -A x64
cmake --build build --config Release
```

Standalone and VST3 targets are generated by JUCE. Look under `build/CyberDistortion_artefacts/Release/`.

## Current scope

This initial scaffold only passes audio through unchanged and displays a simple dark/orange GUI. The exposed parameter state is groundwork; no distortion, level processing, metering, oversampling, filtering or clipping is implemented yet. Validate the build locally before moving to DSP.
